# Room Booking App — Приложение для бронирования переговорных комнат

Учебный проект: SPA-приложение для просмотра переговорных комнат и бронирования свободных слотов времени.

## О проекте

Приложение позволяет пользователю:
- Просматривать список доступных переговорных комнат;
- Открывать карточку комнаты и смотреть её расписание на день (слоты с 09:00 до 20:00);
- Бронировать свободные слоты;
- Просматривать свои бронирования;

## Как запустить проект

Требования:
- Установленный Node.js (версия 18 или выше) — https://nodejs.org/

Установка и запуск:

1. Перейти в папку с проектом:

   cd room-booking-app

2. Установить зависимости:

   npm install

3. Запустить dev-сервер:

   npm run dev

4. Открыть в браузере:

   http://localhost:5173

После запуска вы увидите список комнат.
