# Room Booking App — Приложение для бронирования переговорных комнат
Ссылка на задание: https://github.com/avito-tech/tech-internship/blob/main/Tech%20Internships/Frontend/Frontend-trainee-assignment-autumn-2026/Frontend-trainee-assignment-autumn-2026.md

Учебный проект: SPA-приложение для просмотра переговорных комнат и бронирования свободных слотов времени.

## О проекте

Приложение позволяет пользователю:
- Просматривать список доступных переговорных комнат;
- Открывать карточку комнаты и смотреть её расписание на день (слоты с 09:00 до 20:00);
- Бронировать свободные слоты;
- Просматривать и удалять свои бронирования;
  
## Что сделано

- Список переговорных комнат: карточки с названием, вместимостью и описанием.
- Переход из карточки комнаты на её страницу расписания.
- Страница комнаты: отображается название выбранной комнаты.
- Сетка временных слотов на странице комнаты: с 09:00 до 20:00, с шагом 1 час.
- Кнопка «Забронировать» на каждом слоте (визуальная, без отправки запроса).
- Кнопка «Назад к списку» для возврата на страницу комнат.
- Верхняя навигация: переход между разделами «Комнаты» и «Мои брони».
- Страница «Мои брони».

## Что не сделано

- Создание и отмена реального бронирования через API.
- Обработка ошибки 409 (конфликт бронирования).
- Real-time обновления занятости слотов через WebSocket.
- Loading / error / empty состояния.
- Фильтры в списке комнат.
- Юнит-тесты (Vitest + React Testing Library).
- Дополнительные задания (reconnect с resync, real-time обновление списка комнат, оптимистическая отмена с rollback, экспорт .ics, повторяющиеся бронирования).

## Как запустить проект

Требования:
- Установленный Node.js (версия 18 или выше) — https://nodejs.org/

Установка и запуск:

1. Перейти в папку с проектом:

   cd room-booking-app

2. Установить зависимости:

   npm install

3. Запустить dev-сервер:

   npm run dev

4. Открыть в браузере:

   http://localhost:5173

После запуска вы увидите список комнат.
